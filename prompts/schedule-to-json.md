# Преврати текст расписания в JSON

Я вставлю ниже расписание богослужений. Подготовь **один JSON-файл для одного месяца и одного языка**, который примет генератор расписания. Не создавай HTML.

Правила:

1. Ничего не выдумывай. Не добавляй даты, службы, время, часы работы или священников, которых нет в тексте. Не заменяй неизвестное «типичным» расписанием.
2. Описания дней, имена святых, названия служб, часы работы и подписи священников переноси как есть. Можно исправлять только пробелы и очевидные технические переносы строк. Разные тире в исходнике не определяют тип поля: опирайся на смысл и структуру. Не переводи текст.
3. Если год, месяц, язык, дата, время **или принадлежность строки конкретной службе** неясны, сначала задай короткий уточняющий вопрос. Не выдавай JSON до ответа. Если непонятно, является ли строка службой или описанием дня, тоже спроси.
4. Не пытайся вычислять праздники или расставлять красный цвет: это делает генератор.
5. Ответь в двух частях: сначала только валидный JSON без комментариев и Markdown-ограждения; затем с новой строки одну короткую подсказку: «Скопируйте только JSON, откройте `start-mac.command` (Mac) или `start-windows.bat` (Windows) в папке генератора, вставьте JSON и нажмите „Проверить и сохранить HTML“». Если тебе доступна папка проекта, вместо инструкции можешь сам сохранить файл, проверить его командой `python3 src/generate.py --check schedule.json`, запустить генератор и назвать путь к HTML.

Контракт (полная машиночитаемая схема лежит в `schema/month.schema.json`):

```json
{
  "year": 2026,
  "month": 4,
  "language": "ru",
  "days": [
    {
      "date": "2026-04-07",
      "description": ["Строка описания дня"],
      "services": [
        {"time": "10:00", "title": "Название службы", "hours": "", "priest": ""}
      ]
    }
  ]
}
```

Все поля обязательны, лишних полей нет. `year` — число 1900–2099, `month` — число 1–12, `language` — код языка из `settings.json` (по умолчанию `ru` или `en`). Каждая `date` — настоящая гражданская дата `YYYY-MM-DD` этого месяца, без повторов. `description` — массив строк, `services` — массив служб. Каждая служба имеет время начала строго `HH:MM` в 24-часовом формате и три строки `title`, `hours`, `priest`; если часов или священника нет в источнике, ставь `""`. Если указан день без служб, `services` может быть пустым массивом. Дни можно перечислять не по порядку — программа отсортирует их.

Важное условие: если у тебя возникло сомнение при сопоставлении исходного текста полям схемы, задай вопрос вместо заполнения наугад.
