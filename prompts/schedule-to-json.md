# Помоги мне получить HTML расписания для сайта

Я не программист и не умею пользоваться терминалом. Ниже я вставлю текст расписания. Преврати его в JSON для генератора и проведи меня по шагам до готового HTML. Общайся простыми словами; поясняй, куда нажать, что скопировать и какой результат ждать.

## Сначала уточни

Если моя система не указана, сначала спроси: «У вас Mac или Windows?» Дождись ответа; не определяй систему по языку расписания. Если папка генератора ещё не скачана и не распакована, помоги с этим; не выдумывай ссылку на загрузку, попроси ссылку или архив, который мне передали.

Если год, месяц, язык, дата, время или принадлежность строки конкретной службе неясны, спроси. Не выдавай окончательный JSON, пока неоднозначности не разрешены.

## Подготовь JSON

Ничего не выдумывай. Не добавляй службы, время, священников или календарные описания. Текст святых и служб переноси как есть: можно исправлять только пробелы и технические переносы строк. Не переводи. Если неясно, является ли строка службой или описанием дня, спроси. Календарное выделение праздников выполняет генератор.

Один файл — один месяц и один язык. Все поля обязательны, лишних полей нет. Схема лежит в `schema/month.schema.json`; краткий контракт:

```json
{
  "year": 2026,
  "month": 4,
  "language": "ru",
  "days": [
    {
      "date": "2026-04-07",
      "description": ["Описание дня как в источнике"],
      "services": [
        {"time": "10:00", "title": "Название службы", "hours": "", "priest": ""}
      ]
    }
  ]
}
```

`year` — целое число 1900–2099, `month` — 1–12. `language` — код из `settings.json` (изначально `ru` и `en`); для другого языка помоги добавить подписи месяцев и дней недели. `date` — реальная гражданская дата `YYYY-MM-DD` внутри указанного месяца; повторы запрещены. `description` — список строк, `services` — список служб. `time` строго `HH:MM`, `title` — непустая строка. `hours` — полная строка о часах работы храма (например, «Храм открыт с 16:30»), `priest` — полная подпись священника (например, «Священник: пример»). Сохраняй эти подписи и префиксы как в источнике. Если сведений нет, используй `""`. Если неясно, к какой службе относятся часы или священник, спроси. Для дня без служб допускается `services: []`.

После уточнений выдай JSON отдельным блоком для копирования. Внутри него не должно быть комментариев или инструкций. После JSON дай следующие шаги **только для моей системы**. Не требуй, чтобы я понимал код. Если я застрял, объясни один ближайший шаг и дождись результата.

## Проведи меня от JSON до HTML

1. **Сохранить JSON.** Объясни, что нужна папка, внутри которой видны `src`, `settings.json` и `README.md`. Файл `schedule.json` нужно сохранить туда, рядом с ними, а не внутрь `src`. Копировать надо только содержимое блока JSON — без строк с тройными обратными кавычками и без пояснений.
   - Mac: открыть TextEdit, создать документ, выбрать «Формат → Сделать простым текстом», вставить JSON и сохранить в UTF-8 как `schedule.json`. Если предлагается добавить `.txt`, отказаться; если файл уже назван `schedule.json.txt`, переименовать в Finder и подтвердить использование `.json`.
   - Windows: открыть Блокнот, вставить JSON, «Сохранить как», выбрать «Все файлы», имя `schedule.json`, кодировку UTF-8. Проверить, что не получилось `schedule.json.txt`; расширения видны через «Вид → Показать → Расширения имён файлов» в Проводнике.
2. **Открыть терминал в папке.** Объясни, что терминал — окно для ввода команд; каждую команду вставляют отдельно и нажимают Enter.
   - Mac: открыть «Терминал» через Spotlight (Cmd+Пробел). Напечатать `cd` и пробел, перетащить папку генератора из Finder в окно терминала, нажать Enter. Затем `ls`: среди файлов должны быть `src`, `settings.json`, `schedule.json`.
   - Windows: открыть папку генератора в Проводнике, щёлкнуть адресную строку, ввести `powershell` и нажать Enter. Затем `dir`: должны быть видны те же файлы. Не проси вводить выдуманный абсолютный путь.
3. **Проверить Python.** На Mac дать `python3 --version`, на Windows — `py -3 --version`. Нужна версия 3.10 или новее. Если на Windows `py` не найден, попробовать `python --version`; при успехе использовать `python` в обеих дальнейших командах.
   - Если Python отсутствует или старее 3.10, помоги установить поддерживаемый Python с официального [python.org/downloads](https://www.python.org/downloads/). На Mac открыть скачанный `.pkg` и пройти установщик. На Windows следовать официальной странице установки: установить Python Install Manager и Python 3; если менеджер не установил интерпретатор автоматически, выполнить `py install 3`. Не советуй устанавливать дополнительные библиотеки — они не нужны. Уточняй шаг по сообщению установщика, если его экран отличается.
   - После установки закрыть и заново открыть терминал **в папке генератора**, повторить проверку версии. Не продолжать, пока команда не показывает подходящую версию. При неожиданном сообщении попросить скопировать его в чат.
4. **Проверить и создать HTML.** Дай две команды отдельными блоками, с пояснением после каждой. Выполнять вторую только после успешной первой.
   - Mac:
     `python3 src/generate.py --check schedule.json`
     затем `python3 src/generate.py schedule.json schedule.html`.
   - Windows:
     `py -3 src/generate.py --check schedule.json`
     затем `py -3 src/generate.py schedule.json schedule.html`.
     Если проверка версии прошла только через `python`, замени `py -3` на `python` в обеих командах.
   Первая команда должна вывести «JSON проверен: дней …». Вторая — «Создано: schedule.html; дней: …». Файл появится рядом с `schedule.json`.
5. **Разобраться с ошибкой.** Попроси скопировать полное сообщение из терминала в этот же чат. Если ошибка в JSON, выдай исправленный полный JSON без потери исходного текста, попроси заменить содержимое `schedule.json` и снова выполнить `--check`. Если данных не хватает, уточни их. Если не найден файл, помоги проверить папку и расширение `.json.txt`. Не советуй отключать проверку. Не говори, что файл создан, если пользователь не получил сообщение об успехе.
6. **Вставить HTML на сайт.** Двойной щелчок по `schedule.html` открывает просмотр в браузере; это удобно для проверки внешнего вида. Для сайта нужен исходный код файла:
   - Mac: в Терминале из папки генератора выполнить `pbcopy < schedule.html`, чтобы скопировать весь HTML; затем вставить в поле HTML на сайте.
   - Windows: правой кнопкой на `schedule.html` → «Открыть с помощью → Блокнот», Ctrl+A и Ctrl+C; затем вставить в поле HTML на сайте.
   Укажи Тильду T123, WordPress «Произвольный HTML» или аналогичный блок «Свой HTML». Не предлагай копировать видимый текст из окна браузера. Для второго языка повторить путь с отдельными именами JSON и HTML, чтобы не перезаписать первый результат.

Не утверждай, что запускал код или создал файл: в этом чат-сценарии команды выполняю я, а ты помогаешь по моим сообщениям.
