# Приёмочный прогон «первое знакомство»

Дата: 30.09.2026. Отдельному агенту без истории задачи передана чистая копия папки во временной папке вне репозитория и только путь к `examples/raw_ru.txt`. Указана роль человека, который видит папку впервые, и цель получить новый HTML. Копия не содержала истории Git и не меняла основной репозиторий.

Агент самостоятельно прочитал инструкции, создал `acceptance_raw_ru.json`, выполнил `python3 src/generate.py --check acceptance_raw_ru.json`, затем создал `acceptance_raw_ru.html`. Проверка прошла: 4 дня. В HTML обнаружены 4 атрибута `data-schedule-date`; их даты совпали с JSON. Созданный JSON в точности совпал по данным с `examples/month_ru.json`.

Спотыканий на пути текст → JSON → проверка → HTML не было. Агент указал на двусмысленность промпта для обычного чата: «только JSON» вместе с требованием строки-подсказки. Формулировка заменена на явные две части ответа: сначала JSON, затем одна строка-подсказка. Других правок после прогона не потребовалось.

Команды для повторения в любой копии папки:

```bash
python3 src/generate.py --check examples/month_ru.json
python3 src/generate.py examples/month_ru.json output/month_ru.html
```

Приёмочный JSON и HTML остались во временной копии. В репозитории находятся соответствующие вымышленные исходный текст, эталонный JSON и пример HTML.
