# Приёмочный прогон по подсказкам промпта

Дата: 30.09.2026. Отдельному агенту без истории разговора передана чистая копия папки без Git и исходный `examples/raw_ru.txt`. Роль: человек, который видит папку впервые и не знает терминал. Единственной инструкцией был `prompts/schedule-to-json.md`; README, AGENTS, код, схема и эталонный JSON не читались.

## Пройденный путь

Смоделирован диалог: система сначала неизвестна, помощник спрашивает «У вас Mac или Windows?», пользователь отвечает «Mac». Затем из исходного текста подготовлен новый `schedule.json`. Сохранение через TextEdit и переход в папку через Finder смоделированы файловыми инструментами; команды ниже выполнены реально из папки копии.

| Команда | Результат |
|---|---|
| `ls` | Найдены `src`, `settings.json`, `schedule.json` |
| `python3 --version` | Python 3.14.7 |
| `python3 src/generate.py --check schedule.json` | JSON проверен: дней 4 |
| `python3 src/generate.py schedule.json schedule.html` | Создано: schedule.html; дней: 4 |

После прогона основной агент сравнил JSON с эталоном: данные полностью совпали. В HTML четыре атрибута `data-schedule-date`: 4, 5, 7 и 12 апреля 2026 года. Исходные тексты и время служб сохранены.

## Найденное и исправления

Промпт не объяснял назначение `hours` и необходимость сохранять подпись `priest` целиком. Добавлены определения с примерами «Храм открыт с 16:30» и «Священник: пример», а также правило уточнять неоднозначную принадлежность службе.

Агент заметил, что заключительный абзац промпта позволял перескочить на автоматический путь. Он удалён из чат-промпта; самостоятельное выполнение агентом описано в AGENTS.md и README. Теперь обычный чат ведёт пользователя по шагам, а агент с доступом к файлам выполняет работу сам.

## Границы проверки

Команды и создание HTML проверены на Mac с установленным Python. Копирование из чата, сохранение через TextEdit и открытие терминала через Finder смоделированы, а не проверены человеком в интерфейсе. Windows и отсутствие Python разобраны по тексту инструкций; установка ПО не выполнялась. Справка по установке сверена с официальной документацией [для macOS](https://docs.python.org/3/using/mac.html) и [для Windows](https://docs.python.org/3/using/windows.html).

Визуальный просмотр через приёмочный браузер не выполнен: он не разрешил локальный `file://`. HTML проверен чтением файла; публикация на сайте и копирование в системный буфер не выполнялись. Этот прогон подтверждает получение HTML по подсказкам промпта, но не заменяет пользовательскую проверку интерфейсов обеих систем.
