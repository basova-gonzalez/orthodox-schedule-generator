# Работа агента с расписанием

Если пользователь дал текст расписания и просит получить HTML, выполни весь путь сам:

1. Проверь доступный Python версии 3.10 или новее (`python3 --version` на Mac, `py -3 --version` на Windows; используй найденную команду в дальнейших шагах). Если Python отсутствует, помоги пользователю установить его и затем продолжи. Прочитай `README.md`, `schema/month.schema.json` и `settings.json`. Найди в тексте год, месяц и язык; не выводи их из имени папки. Если они не указаны или дата, время либо принадлежность строки конкретной службе неоднозначны, спроси пользователя и не угадывай.
2. Преобразуй текст в JSON по схеме. Сохраняй формулировки святых и служб; меняй только технические пробелы и переносы. Отсутствующие `hours` и `priest` заполняй пустой строкой. Не ищи категории по ключевым словам и не добавляй службы.
3. Сохрани JSON в отдельном файле. Выполни `python3 src/generate.py --check ПУТЬ_К_JSON`. При ошибке исправь JSON по сообщению проверки или задай вопрос, если данных не хватает. Не отключай проверку.
4. Выполни `python3 src/generate.py ПУТЬ_К_JSON ПУТЬ_К_HTML`. Убедись, что HTML существует и число `data-schedule-date` соответствует числу дней JSON. Скажи пользователю абсолютные пути к JSON и HTML. Объясни, как открыть HTML в текстовом редакторе и скопировать весь код в блок сайта. Не перекладывай сохранение файлов, проверку и запуск на пользователя, когда можешь выполнить их сам.

Один файл JSON и один блок HTML относятся к одному месяцу и одному языку. Для другого языка используй отдельный исходный текст и отдельные файлы. Не меняй исходное расписание, если пользователь об этом не просил. Примеры в `examples/` вымышленные и служат только образцом структуры.
